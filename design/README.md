# TerraShift — дизайн (Apple-стиль)

Исходники экранов для канваса Design. Каждый `*.dc.html` — отдельный артборд.

| Файл | Что это |
| --- | --- |
| `Landing.dc.html` | Первый экран: глобус, навигация, маркеры (1:1 к референсу) |
| `Welcome.dc.html` | Вторая версия приветствия: звёздный фон, Земля из космоса, серифный заголовок |
| `WelcomePhone.dc.html` | Та же версия для телефона, 390 px |
| `Main.dc.html` | Главная: выбор поля, слайдеры, рейтинг севооборотов |
| `Rotations.dc.html` | Сравнение севооборотов с диапазонами |
| `Climate.dc.html` | Климат: графики до/после, прогноз до 2040, заморозки |
| `Crops.dc.html` | Таблица культур с горизонтальной прокруткой |
| `Now.dc.html` | Последние 30 дней и прогноз |
| `Sources.dc.html` | Источники, статусы, методы, предупреждения |
| `Phone.dc.html` | Главная в 390 px, тёмная тема |
| `canvas.json` | Индекс артбордов канваса |

- `assets/` — текстуры: глобус (NASA Blue Marble), звёздный фон, Земля из космоса.
- `scripts/` — генераторы текстур (`globe.py`, `space.py`). Пути внутри скриптов указывают на рабочую папку, их нужно поправить под себя.

Файлы рассчитаны на запуск внутри канваса Design: им нужен `support.js` канваса. Открыть напрямую в браузере без него они не будут.

Данные в макетах — из реального прогона анализа (Джизак, NASA POWER, 2011–2025). Карта и прогноз Open-Meteo — заглушки.
